## <img src="https://github.com/KrishBharadwaj5678/Gestune/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
|----------|-------------|
| 🖐️ **Gestos com as Mãos** | Controle o volume do sistema usando gestos intuitivos com as mãos |
| 🧠 **Rastreamento com IA** | Utiliza MediaPipe e OpenCV para um rastreamento preciso das mãos |
| 🔊 **Integração com o Sistema** | Integra-se perfeitamente aos controles de áudio do sistema usando **PyCaw** |
| 🚀 **Leve e Eficiente** | Rápido, eficiente e fácil de configurar para uma experiência de uso agradável |

## <img src="https://github.com/KrishBharadwaj5678/Gestune/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Gestune.git
````

 ### 2️⃣ Acesse a Pasta do Projeto

```bash
cd Gestune
```

 ### 3️⃣ Execute o Script

```bash
python VolumeHandControl.py
```

## <img src="https://github.com/KrishBharadwaj5678/Gestune/raw/main/assets/readme/howItWorks.gif" width="35"/> Como Funciona

- 🤏 **Aproxime** o polegar e o dedo indicador para diminuir o volume.
- ✋ **Afaste** o polegar e o dedo indicador para aumentar o volume.
