## <img src="https://github.com/KrishBharadwaj5678/Gestune/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
|----------|-------------|
| 🖐️ **Жесты рук** | Управление системной громкостью с помощью интуитивно понятных жестов |
| 🧠 **Отслеживание с помощью ИИ** | Использует MediaPipe и OpenCV для точного отслеживания положения руки |
| 🔊 **Интеграция с системой** | Плавное управление системным звуком с помощью **PyCaw** |
| 🚀 **Лёгкость** | Быстрая, эффективная и простая настройка для комфортного использования |

## <img src="https://github.com/KrishBharadwaj5678/Gestune/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

```bash
git clone https://github.com/KrishBharadwaj5678/Gestune.git
````

 ### 2️⃣ Переход в папку проекта

```bash

```

 ### 3️⃣ Запуск скрипта

## <img src="https://github.com/KrishBharadwaj5678/Gestune/raw/main/assets/readme/howItWorks.gif" width="35"/> Как это работает

- 🤏 **Сведите** большой и указательный пальцы вместе, чтобы уменьшить громкость.
- ✋ **Разведите** большой и указательный пальцы, чтобы увеличить громкость.
