<h1 align="center">
  <img src="https://github.com/KrishBharadwaj5678/Gestune/blob/main/assets/icons/gestune.png" width="35"/>
  Gestune
</h1>

<p align="center">
  手のジェスチャーを使ってシステム音量を簡単に操作できます。キーボードやマウスを使わずに、直感的かつ快適に音量を調整できます。
</p>

## <img src="https://github.com/KrishBharadwaj5678/Gestune/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
|----------|-------------|
| 🖐️ **ハンドジェスチャー** | 直感的な手のジェスチャーでシステム音量を操作 |
| 🧠 **AIによるトラッキング** | MediaPipeとOpenCVを使用して手を正確にトラッキング |
| 🔊 **システム統合** | **PyCaw**を使用してシステムのオーディオ・音量をシームレスに操作 |
| 🚀 **軽量** | 高速・効率的で、簡単にセットアップでき、快適に使用可能 |

## <img src="https://github.com/KrishBharadwaj5678/Gestune/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Gestune.git
````

 ### 2️⃣ プロジェクトフォルダへ移動

```
cd Gestune
```

 ### 3️⃣ スクリプトを実行

```
python VolumeHandControl.py
```

## <img src="https://github.com/KrishBharadwaj5678/Gestune/raw/main/assets/readme/howItWorks.gif" width="35"/> 仕組み

- 🤏 **親指と人差し指を近づける**と、音量が下がります。
- ✋ **親指と人差し指を離す**と、音量が上がります。
