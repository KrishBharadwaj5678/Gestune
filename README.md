<p align="center">

## <img src="https://github.com/KrishBharadwaj5678/Gestune/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature | Description |
|----------|-------------|
| 🖐️ **Hand Gestures** | Control system volume using intuitive hand gestures |
| 🧠 **AI-Powered Tracking** | Uses MediaPipe and OpenCV for accurate hand tracking |
| 🔊 **System Integration** | Seamlessly integrates with system audio controls using **PyCaw** |
| 🚀 **Lightweight** | Fast, efficient, and simple to set up for a smooth user experience |

## <img src="https://github.com/KrishBharadwaj5678/Gestune/raw/main/assets/readme/howItWorks.gif" width="35"/> How it Works 

- 🤏 **Pinch** your thumb and second finger together to decrease the volume.
- ✋ **Spread** your thumb and second finger apart to increase the volume.
